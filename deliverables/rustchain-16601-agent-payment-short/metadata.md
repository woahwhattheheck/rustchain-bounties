## Description

Beacon includes a RustChain transport for Ed25519-signed RTC transfers. This short breaks down the public CLI example and the code path behind it: recipient, amount, memo and nonce are serialized, signed locally, then sent to RustChain's signed-transfer endpoint.

Source code and docs: https://github.com/Scottcjn/beacon-skill

No private keys or live funds are required for the capture plan.
