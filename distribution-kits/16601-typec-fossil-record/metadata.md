## Short description

RustChain’s Fossil Record visualizer turns hardware-attestation history into a geological-style timeline of CPU architectures. This short shows what the source actually records, how timestamps map into ~24-hour epochs, and how the UI exposes architecture layers, first appearances, filters, hover details, and CSV export.
