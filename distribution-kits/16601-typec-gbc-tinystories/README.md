A stock Game Boy Color runs a quantized TinyStories-260K transformer locally: one prompt plus 15 generated tokens takes 16 transformer forward passes and about 45 minutes on real hardware.

## Accuracy boundary

The source repository describes this as a proof of concept, not a polished text generator. Its real-hardware README result reports an estimated ~45-minute run for one 1-token prefill plus 15 generated tokens, about 0.0059 tokens/sec, with imperfect but recognizable output. This kit preserves those caveats and does not turn the result into a speed or product-readiness claim.
